# Business Intelligence Analyst - React Frontend

Modern React application for the Small Business Intelligence Analyst cognitive computing system.

## Features

- 🎨 Modern UI with Material-UI
- 📊 Interactive charts and visualizations
- 🔄 Real-time sentiment analysis
- 📈 Trend forecasting
- 🎯 Topic discovery
- 📱 Responsive design

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Material-UI (MUI)
- Recharts
- Vite
- Axios

## Backend API

The frontend expects a backend API running on `http://localhost:5000/api`. See the backend README for API setup.
