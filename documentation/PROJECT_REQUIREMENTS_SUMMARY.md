# Cognitive Computing Project - Requirements Summary

## Course Information
- **Course Code**: DSC3112
- **Course Name**: Cognitive Computing
- **Program**: Bachelor of Science in Data Science & Analytics, Year 3, Semester 1
- **University**: Uganda Christian University
- **Exam Type**: 100% Project-Based Exam
- **Duration**: 2 weeks (December 2025)

## Project Overview

This is an **individual project-based exam** where students must architect a functional cognitive system that embodies the four pillars of cognitive computing:

1. **Understand**: System must interpret context, ambiguity, and meaning from unstructured human language
2. **Reason**: System must use its knowledge base to reason and arrive at sound answers
3. **Learn**: System should incorporate new data or user feedback to refine performance over time
4. **Interact**: System must communicate complex reasoning back to users in a simple, clear, and context-aware manner

## Project Scenarios (Choose ONE)

### Scenario 1: Agricultural Advisory Agent
- **Problem**: Small-scale farmer submits photo of crop disease + query in mixed Luganda/English
- **Key Capabilities**: Natural Language Processing, Image Classification, Knowledge Graphs
- **Datasets**: PlantVillage Dataset, Ugandan weather data, local crop information

### Scenario 2: Community Health Diagnostic Assistant
- **Problem**: Village Health Team member describes patient symptoms in unstructured text
- **Key Capabilities**: Natural Language Processing, Machine Learning (Probabilistic Reasoning), Knowledge Representation
- **Datasets**: Public disease symptom data, Uganda Ministry of Health data

### Scenario 3: Personalized Educational Recommender
- **Problem**: Student struggling with a topic (e.g., Quantum computing) requests explanation
- **Key Capabilities**: Recommendation Systems, Natural Language Processing, Knowledge Graphs
- **Datasets**: Open-source educational content, learning materials

### Scenario 4: Small Business Intelligence Analyst
- **Problem**: Business owner wants to understand customer sentiment and market trends
- **Key Capabilities**: Sentiment Analysis, Topic Modeling (NLP), Predictive Modeling
- **Datasets**: Local business news, public social media data, market data

## Project Structure

### PART A: PROBLEM ANALYSIS & SYSTEM DESIGN [30 Marks]

#### Task A1: Problem Analysis Document [10 Marks]
- Define chosen scenario within Ugandan context
- Analyze key stakeholders and user personas
- Justify project's relevance to local development goals
- Conduct brief literature review of existing/similar solutions

#### Task A2: System Architecture & Cognitive Design [10 Marks]
- Complete system architecture diagram
- Detailed Cognitive Processing Pipeline diagram showing data flow
- Explicitly map components to Understand, Reason, Learn, and Interact pillars

#### Task A3: Implementation Plan [10 Marks]
- Professional project plan
- Detailed work breakdown structure
- Project timeline with clear milestones
- Risk assessment with mitigation strategies

### PART B: COGNITIVE SYSTEM IMPLEMENTATION [50 Marks]

#### Task B1: Data Perception & Preparation [10 Marks]
- Implement robust data pipeline in Python notebook
- Acquire, clean, and preprocess chosen datasets
- Transform raw, unstructured data into clean, standardized format

#### Task B2: The Understanding & Reasoning Engine [20 Marks]
**Must implement and integrate at least TWO of the following:**
1. **Natural Language Processing**: Techniques that capture deep meaning
2. **Knowledge Graph Construction**: Extract entities and relationships to build structured knowledge base
3. **Machine Learning Models**: Train and validate model for classification/prediction/reasoning
4. **Multimodal Understanding**: Process non-text data (images, audio) and integrate with text analysis

#### Task B3: The Interaction Layer [20 Marks]
- Working prototype with web-based or chatbot interface
- Allow users to interact and receive responses from reasoning engine
- Demonstrate complete cognitive cycle from input to output

### PART C: EVALUATION & PROFESSIONAL DELIVERABLES [20 Marks]

#### Task C1: System Evaluation Report [10 Marks]
- Rigorous evaluation of prototype performance
- Analyze strengths and weaknesses using quantitative metrics and qualitative observations
- Compare cognitive approach to simpler baseline method (e.g., keyword-based search)
- Recommendations for future improvements

#### Task C2: Ethical & Impact Analysis [5 Marks]
- **Data Bias and Fairness**: Investigate training data for biases (linguistic, regional, demographic)
- **Data Privacy and Contextual Appropriateness**: Outline measures to protect user data
- Discuss cultural and contextual appropriateness for Ugandan users

#### Task C3: Professional Deliverables [5 Marks]
- Complete and professional project package
- Comprehensive final report
- Polished presentation slides
- Well-documented code repository with clear user manual
