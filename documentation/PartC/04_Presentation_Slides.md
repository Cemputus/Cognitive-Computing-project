## Slide 2: Problem Statement

**The Challenge**

Small businesses in Kampala, Uganda struggle with:
- 📊 Understanding customer sentiment from reviews
- 🔍 Identifying key topics in feedback
- 📈 Tracking market trends
- ⏱️ Time-consuming manual analysis

**The Need**: Automated cognitive system for business intelligence

---

## Slide 3: Solution Overview

**Our Approach**

A cognitive computing system that:
- ✅ **Understands** customer feedback through NLP
- ✅ **Reasons** about insights using knowledge graphs
- ✅ **Learns** from user feedback
- ✅ **Interacts** through modern web interface

**Technology**: Python, React, Machine Learning, NLP

## Slide 5: Key Features

**System Capabilities**

1. **Sentiment Analysis**
   - VADER and TextBlob
   - 85.2% accuracy
   - Handles negations and context

2. **Topic Modeling**
   - LDA-based topic discovery
   - 5 key topics identified
   - Business-relevant themes

3. **Predictive Modeling**
   - Time series forecasting
   - 3 methods (MA, Linear, ARIMA)
   - Trend predictions

4. **Knowledge Graphs**
   - Entity relationships
   - 71 nodes, 1,295 edges
   - Dynamic graph construction

## Slide 9: Cognitive Pillars - Understand

**Natural Language Processing**

- **Text Preprocessing**: Cleaning, tokenization, lemmatization
- **Sentiment Analysis**: VADER and TextBlob analyzers
- **Entity Extraction**: Keywords and phrases
- **Output**: Structured understanding of text meaning

**Example**: "Great service but slow delivery"
→ Sentiment: Mixed (Positive service, Negative delivery)

## Slide 10: Cognitive Pillars - Reason

**Knowledge Graphs & Machine Learning**

- **Knowledge Graph**: 71 nodes, 1,295 relationships
- **Topic Modeling**: LDA identifies 5 key topics
- **ML Classification**: Logistic Regression (85.2% accuracy)
- **Predictive Modeling**: Time series forecasting

**Example**: Entity "service" → connected to "positive" sentiment → Topic "Customer Service"
